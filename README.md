# BrainGCN-SR: Brain Graph Super-Resolution

Predicts high-resolution (268×268) brain connectivity graphs from low-resolution (160×160) graphs using a GCN-based architecture. Designed for the DGL 2026 Brain Graph Super-Resolution Challenge.

## Architecture

### Overview

```
LR Graph (160×160) → GCN Encoder → Multi-Scale Features → MLP → Upscale → Bilinear Decoder → HR Graph (268×268)
```

The entire pipeline is **permutation equivariant** — applying any node permutation to the input produces the same permutation in the output.

### Step-by-Step

**1. Input & Node Features**

The input is a 160×160 symmetric adjacency matrix. Each node's feature vector is its row in the adjacency matrix (i.e., its connectivity profile to all other nodes), giving an initial feature matrix of shape (160, 160).

**2. Adjacency Normalization**

Self-loops are added and symmetric normalization is applied:

$$\hat{A} = D^{-1/2}(A + I)D^{-1/2}$$

**3. 3-Layer GCN Encoder**

Three GCN layers, each with output dimension 256:

| Layer | Input → Output | Activation | Residual |
|-------|---------------|------------|----------|
| GCN 1 | (160, 160) → (160, 256) | ReLU + Dropout(0.1) | — |
| GCN 2 | (160, 256) → (160, 256) | ReLU + Dropout(0.1) | + Layer 1 output |
| GCN 3 | (160, 256) → (160, 256) | None (last layer) | + Layer 2 output |

Each GCN layer computes: `X' = Â X W + b`

Residual connections are added between layers with matching output dimensions. With uniform width [256, 256, 256], every consecutive pair has a residual connection, which stabilises training.

**4. Multi-Scale Feature Concatenation**

All three layer outputs are concatenated along the feature dimension:

```
z_lr = [h1 | h2 | h3]  →  shape (160, 768)
```

This captures both local structure (early layers) and higher-order neighbourhood information (later layers).

**5. MLP Projection**

A 2-layer MLP projects the 768-dim multi-scale features into a 128-dim edge embedding space:

```
Linear(768 → 128) → ReLU → Linear(128 → 128)
```

This is a per-node operation (applied identically to each node), preserving permutation equivariance.

**6. Learned Upscaling**

A learned matrix U ∈ ℝ^(268×160) maps from 160 LR nodes to 268 HR nodes:

```
z_hr = U @ z_lr  →  shape (268, 128)
```

Each HR node embedding is a learned linear combination of LR node embeddings.

**7. Bilinear Edge Decoder**

Edge weights are predicted via a bilinear function with a learned weight matrix W ∈ ℝ^(128×128):

```
A_raw = z_hr @ W @ z_hr^T        (268, 268)
A_sym = (A_raw + A_raw^T) / 2    symmetrise
A_pred = sigmoid(A_sym)           clamp to [0, 1]
```

The predicted edge between nodes i and j is: `A[i,j] = σ(z_i^T W z_j)`. Explicit symmetrisation ensures the output graph is undirected.

The upper triangle (35,778 unique edges) is extracted as the output vector.

## Training

- **Loss**: L1 (MAE) between predicted and ground-truth HR edge vectors
- **Optimiser**: Adam (lr=0.001, weight_decay=1e-4)
- **LR Schedule**: Cosine annealing (0.001 → 1e-5 over 500 epochs)
- **Early Stopping**: Patience 50 epochs, restores best model weights
- **Gradient Clipping**: Max norm 1.0
- **Data Augmentation**: Gaussian noise (σ=0.005) added to LR inputs during training, clamped to ≥0, re-symmetrised. Effectively increases the small training set (167 samples).

## Evaluation

3-fold cross-validation with the following metrics:
- **MAE**: Mean Absolute Error on edge weights
- **PCC**: Pearson Correlation Coefficient
- **JSD**: Jensen-Shannon Divergence
- **Centrality MAEs**: Betweenness, Eigenvector, PageRank, Closeness, Degree

## Kaggle Submission

Test predictions are generated by averaging predictions from all 3 fold models (ensemble). Each fold model was trained on 2/3 of the data with proper early stopping on the remaining 1/3.
